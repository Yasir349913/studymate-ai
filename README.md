# 💡 Overview

StudyMate AI is a full-stack AI-powered learning platform that allows students to upload documents (PDF, PPTX) and interact with them using intelligent, context-aware AI responses.

It is built on **Retrieval-Augmented Generation (RAG)** architecture which ensures:
- Answers are strictly based on uploaded documents
- No hallucinated or fake responses
- Highly accurate academic assistance

---

# ⚙️ Features

- 📄 Upload PDF & PPTX files
- 💬 AI Chat with documents
- 🧠 RAG-based grounded answers
- 🔍 Semantic search using embeddings
- 📊 AI MCQ quiz generator
- 🧩 Flashcard generation system
- 📝 Document summarization
- 🔐 JWT authentication system
- 📚 Chat history saving
